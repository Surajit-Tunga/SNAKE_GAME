# Snake Game

- A simple browser-based Snake game built with HTML, CSS, and JavaScript.
- Use the arrow keys to move the snake around the board.
- Eat the food to grow longer and increase your score.
- Avoid hitting the edges of the board to keep playing.
- Open `index.html` in a browser to start the game.
- Your highest score is saved in the browser's local storage.
- Click Start to begin and Restart to play again after a game over.
- The game displays your current score and elapsed time.
- Have fun improving your high score!
